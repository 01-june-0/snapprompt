저장 후 모달이 닫히고 페이지 하단에 토스트. 3초 후 자동 사라짐. [실행취소]로 즉시 되돌리기 가능.

설계 노트

변수 자동 추출
붙여넣은 본문에서 {{name}}·{{name|기본값}}을 실시간 파싱(200ms debounce). 사용자가 칩을 눌러 추가·수정 가능.
중복은 막지 않음
완전 일치해도 경고만. 출처가 다른 같은 프롬프트를 의도적으로 모으는 경우도 있어서 최종 결정은 사용자 몫.
3초면 끝
제목·폴더·태그는 자동 추정/기억으로 채워둠. 사용자는 확인 후 ⌘↵ 한 번이면 저장 완료.
실행취소 가능
토스트의 [실행취소]로 방금 저장을 즉시 되돌림. 잘못 저장해도 부담 없음. 3초 노출.
출처 자동 기록
현재 탭 URL을 자동 캡처. 나중에 "어디서 봤더라" 추적 가능. 편집·삭제 가능.
Shadow DOM
저장 모달도 콘텐츠 스크립트라 Shadow DOM 격리. 어떤 사이트에서 호출해도 동일한 모양·동작.
