설계 노트

정보 밀도
카드 1개 ≈ 96px → 600px 안에 최대 4개. 검색·필터 칩으로 빠르게 좁혀, 결국 1~2개만 보이게 만드는 게 목표.
2-탭 인터랙션
가장 많이 쓰일 흐름은 [검색 → 삽입] 또는 [⭐ 선택 → 삽입]. 두 번 클릭 안에 끝나도록 액션 버튼을 카드 안에 배치.
변수 시각화
{{name}} 형태의 토큰은 본문에서 보라 컬러 칩으로 강조. 미리보기에서 한눈에 변수 위치 파악.
사이드바 정책
폴더 트리는 기본 숨김. 폴더 칩을 누르면 슬라이드인. 깊은 계층 탐색을 원하는 사용자만 노출, 평소엔 카드 영역 폭 최대화.
상세 뷰의 통계
사용 횟수·마지막 사용·저장 기간을 한 줄에. "내가 진짜 자주 쓰는지" 판단해 정리 결정을 돕기 위함.
빈 상태의 행동 제안
"결과 없음"에서 끝나지 않고, 클립보드 활용까지 안내. 막다른 길에서 다음 행동을 제시하는 게 좋은 UX.
