설계 노트

왜 Spotlight 스타일?
ChatGPT·Claude·Gemini 사용자는 이미 키보드 중심. Cmd-K 패턴은 학습 비용 거의 0. 마우스 안 잡고 발동→검색→Enter→삽입 4단계로 끝남.
매칭 강조
Fuse.js 결과의 매칭 문자는 굵게. "코리뷰" 검색이 "코드 리뷰"를 찾아낸 게 한눈에 보이게.
변수 가시화
모달 라벨에 {{name}} 그대로 모노스페이스 보라 칩. "내가 어떤 변수를 채우는지" 본문 구조와 즉시 매칭됨.
미리보기는 항상 표시
변수 입력 중에도 하단 미리보기에서 실시간으로 치환된 결과를 봄. "이 변수가 본문 어디에 들어가는지" 헷갈리지 않음.
비어있는 변수
기본값도 없고 사용자도 안 채운 변수는 미리보기에서 회색 + 취소선. 그래도 [삽입] 막지 않음 — 일부러 LLM에서 채우려는 케이스 존재.
Shadow DOM
모든 오버레이는 shadowRoot 안에 렌더링. 페이지 CSS(예: 부트스트랩, Tailwind) 침범 없음. z-index는 최대값.
키보드 단축키
피커: ↑↓ 탐색, ↵ 선택, Esc 닫기 · 모달: ⌘↵ 즉시 삽입, Tab 다음 변수.
마지막 값 기억
토글 켜면 같은 프롬프트 재사용 시 직전 입력 자동 채움. 동일 작업 반복(예: 비슷한 코드 시리즈 리뷰)에서 변수 다시 칠 필요 없음.
