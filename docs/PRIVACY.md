# SnapPrompt — 개인정보 처리방침 / Privacy Policy

_최종 업데이트 / Last updated: 2026-06-01_

## 한국어

SnapPrompt는 **사용자의 데이터를 수집·전송·공유하지 않습니다.**

- 저장하는 모든 데이터(프롬프트, 폴더, 태그, 설정, 사용 기록, 백업)는 **사용자의 브라우저 안(`chrome.storage.local`)에만** 보관됩니다.
- 외부 서버로 어떤 정보도 보내지 않으며, 분석 도구·광고·추적기를 사용하지 않습니다.
- 제3자와 데이터를 공유하지 않습니다.
- 백업 파일(JSON)은 사용자가 직접 선택한 위치로 **로컬 다운로드**될 뿐, 어디에도 업로드되지 않습니다.
- 익스텐션을 삭제하면 브라우저에 저장된 데이터도 함께 삭제됩니다.

권한은 오직 핵심 기능(프롬프트 저장·삽입·백업)을 위해서만 사용됩니다. 자세한 권한별 용도는 스토어 등록 정보를 참고하세요.

## English

SnapPrompt **does not collect, transmit, or share any user data.**

- All data (prompts, folders, tags, settings, usage history, backups) is stored **only in your browser** (`chrome.storage.local`).
- Nothing is sent to any external server. No analytics, ads, or trackers are used.
- No data is shared with third parties.
- Backup files (JSON) are downloaded **locally** to a location you choose; they are never uploaded anywhere.
- Removing the extension also deletes the data stored in your browser.

Permissions are used solely to provide the core features (saving, inserting, and backing up prompts). See the store listing for a per-permission explanation.
